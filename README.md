# MENTALCARE AI 💬

**AI Mental Health Chatbot — Empathetic AI Companion**

## Features

- Streamlit app with voice input/output
- Flask backend with interactive chat
- CSV-based rule responses + Hugging Face AI fallback
- Multi-step motivational responses for negative sentiment
- Emoji-styled chat bubbles and pastel theme
- Session-based mood memory (last 10 messages)
- Portfolio-ready UI and GitHub deployable
